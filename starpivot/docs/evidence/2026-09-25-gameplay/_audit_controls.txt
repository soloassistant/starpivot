=== 1. 哪些控件会自己重算，哪些必须再按一次「重新计算」 ===
  自动重算  #scenario = custom
  自动重算  #solarmode = sun
  不动它   #collide = merge   ← 改了之后一句提示都没有，玩家会以为坏了
  不动它   #rscale = 3000   ← 改了之后一句提示都没有，玩家会以为坏了
  不动它   #nfrag = 7   ← 改了之后一句提示都没有，玩家会以为坏了
  不动它   #disp = 0.8   ← 改了之后一句提示都没有，玩家会以为坏了
  不动它   #fmin = 1.0   ← 改了之后一句提示都没有，玩家会以为坏了
  不动它   #starcollide = true   ← 改了之后一句提示都没有，玩家会以为坏了
  自动重算  #bioon = false
  自动重算  #bioon = true
  自动重算  #bioyears = 20
  自动重算  #albedo = 0.55
  自动重算  #greenhouse = 80
  不动它   #years = 4   ← 改了之后一句提示都没有，玩家会以为坏了
  不动它   #samples = 150   ← 改了之后一句提示都没有，玩家会以为坏了
  （对照组：上面「自动重算」的那些改完立刻生效，玩家不会有疑问）
