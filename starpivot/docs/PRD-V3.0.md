## 1. 产品定义

**一句话**：星枢是面向商业航天、深空探测与科研教学的**动力学仿真软件平台**；以高精度轨道与姿态动力学为内核，以**行星本体姿态**为差异化壁垒，以**可验证性**为商业信任基础。

三层市场：

| 层 | 客户 | 规模 | 角色 | 对应内核 |
|---|---|---|---|---|
| **营收主体** | 商业航天：卫星星座、测控、总体单位（国内 600+ 家） | 大 | 现金流、营收 | 慢核 + 任务分析 |
| **差异化** | 深空探测：月球/火星/小行星任务总体单位（10–20 家） | 中，单价高 | 壁垒变现 | 慢核 + 姿态模块 |
| **口碑长尾** | 科研课题组、高校、天文馆、爱好者 | 小 | 引用、渗透、品牌 | 快核 + 教学版 |

## 2. 上市路径（核实过的门槛）

| 板块 | 最低可达标准 |
|---|---|
| 科创板第一套 | 市值 ≥10 亿 + 近一年净利为正 **且营收 ≥1 亿** |
| 北交所标准一 | 市值 ≥2 亿 + 近一年净利 ≥2500 万 + ROE ≥8% |
| 北交所标准二 | 市值 ≥4 亿 + 两年营收均值 ≥1 亿 + 增速 ≥30% |

另有科创属性：近三年研发占比 ≥5% 或累计研发投入 ≥8000 万。

**目标：Y4 营收 1.2 亿，冲击科创板第一套；保守路径走北交所标准一（净利 2500 万）。**

## 3. 目标用户与场景（重排后）

| 优先级 | 用户 | 场景 | 付费原因 |
|---|---|---|---|
| P0 | 卫星星座总体 | 星座构型设计、覆盖分析、星地链路预算 | 直接决定卫星数量与造价 |
| P0 | 测控单位 | 过站预报、任务编排、轨道确定 | 日常运营刚需 |
| P1 | 深空探测总体 | 转移轨道、发射窗口、着陆段、目标天体自转模型 | 竞品在行星本体姿态上弱 |
| P2 | 科研课题组 | 自旋-轨道共振、倾角长期演化、参数扫描 | 可引用、可复现 |
| P2 | 高校/天文馆 | 可交互演示、算例作业、4K 素材 | 教学采购、展项交付 |

## 4. 竞品与差异化

- **任务级软件**：STK（对华禁运）、ATK（国防科大，200+ 单位 2600+ 用户）、洞察者（星图测控，已上市）、CSTK
- **科研代码**：SMERCURY-T、Mercury-T、Posidonius、VPLanet、GRIT、tidev、REBOUNDx、GYRE-tides
- **消费沙盒**：Universe Sandbox、SpaceEngine
- **通用物理引擎**：飞捷科思 Fysics（资本+生态已锁位，不正面竞争）

**差异化三条**：
1. **行星本体姿态**（自转/岁差/潮汐/共振）——竞品弱项，是切入深空探测的唯一理由
2. **可验证性**——标准算例 + 自动比对报告，不是物理炫技
3. **国产化 + 离线私有化**——内核零第三方依赖，天然满足涉密与内网要求

## 5. 功能范围（按营收倒推重排）

### P0 — 决定营收（V1.0 必须具备）
1. 轨道动力学：二体传播、SGP4/SDP4、J2–J4 摄动、高精度数值积分
2. 星座构型：Walker/极轨/倾斜轨道构型设计与维持
3. 覆盖分析：地面站可见性、重访周期、覆盖率统计
4. 链路预算：星地链路、仰角、多普勒
5. 测控任务：过站预报、任务编排与冲突检测
6. 国产化：麒麟/飞腾/海光适配、完全离线与私有化部署

### P1 — 差异化护城河（V1.x）
7. 行星本体姿态：自转、岁差章动、潮汐演化（**已开工，见 `src/spin.cpp`**）
8. 深空任务分析：霍曼/双椭圆/Lambert 转移、发射窗口、C3
9. 着陆段：弹道与动力下降剖面、末端速度
10. 任务剧本与 Δv 预算表

### P2 — 品牌与长尾（V2+）
11. 教学版（按席位）、展馆版
12. `.xsys` 开放协议与 Python SDK
13. 教学竞赛平台、教师资源库
14. Zenodo DOI 与学术引用体系

### 明确不做
通用可微分物理引擎 ｜ 火箭总装与零件级建模 ｜ 发动机/气动/热防护 ｜ 第一人称手动操控 ｜ 自研 SPH 大碰撞（留耦合接口）

## 6. 技术架构与当前实现状态

| 层 | 内容 | 状态 |
|---|---|---|
| 内核（C++17） | `gravity.cpp` 引力与 jerk、`hermite.cpp` 4 阶、`leapfrog.cpp` 辛 2 阶、`elements.cpp` 轨道根数与守恒量、`spin.cpp` 自转与岁差 | **已实现并通过 25 项测试** |
| 绑定 | pybind11 | 已实现（待本机编译 Python 模块） |
| 文件层 | `.xsys` v1.0 规范 + 校验器（10 规则，错误带修复提示） | 已实现 |
| 场景 | `xsys_gen.py`（二体/地月/Figure-8/强摄动/L4） | 已实现 |
| 渲染层 | Three.js + WASM 内核 | 未开始（P1） |
| 任务分析 | 覆盖/链路/测控 | 未开始（P0，下一步） |

**硬约束**：内核 C++17，零第三方数值依赖；全 double；`-O2` 且禁用 `-ffast-math`（另加 `-ffp-contract=off` 保 bit 复现）；Python 仅用于绑定、测试、`.xsys` 生成校验。

## 8. 商业化与财务路径（假设，需校准）

| 年 | 营收 | 主要来源 | 关键动作 |

## 10. 风险与不成立条件

| 风险 | 对策 |
|---|---|
| **垂类市场太小，撑不起上市**（已确认存在） | 已重排边界；若坚持只做姿态，则定位为被并购标的 |
| 进不了商业航天供应链（资质/名录/竞品锁定） | 优先体系外初创；走分包与联合体 |
| ATK / 洞察者向下兼容覆盖差异化 | 加深姿态深度与可验证性两项非通用能力 |
| 被认定为"游戏"失去专业客户 | 专业版与消费版界面分离，不做第一人称操控 |
| 客户集中度过高 | 单客户占比超 30% 触发预警、超 50% 触发结构调整（自律指标） |
| 混沌被误解为预测能力 | 内置 Lyapunov 指示器，界面标注可预测时间尺度 |

**不成立的条件**：只做科研垂类 → Y5 天花板 2000–3000 万，永远上不了市；进不了商业航天 → Y3 卡在 2000 万。
