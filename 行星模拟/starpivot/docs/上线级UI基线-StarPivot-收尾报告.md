第一次，zstd 压缩。Chrome headless、400kbps/50ms、禁缓存、5 轮中位数、同一设备与同一 worktree：

|---|---:|---:|---:|

| zstd level 9 | 740 ms | 2363 ms | 121,182 B |

把上表**全部**实删后实测：gzip 135,135 → **135,031 B，只省 104 B**。离 4 KB 差两个数量级。

唯一能省出 4 KB 以上的"运行时不需要"的字节是注释：整行 `//` 注释删掉省 **54,157 B**，连 `<!-- -->`、`/* */` 一起删省 **56,790 B**（占全文件 42%）。但这不是死代码——它是这个项目的物理口径与判据说明（"为什么不能用 border""为什么这个数来自内核"），删它属于规则 3 禁止的"换写法"，并且会让后续每一次回归都失去依据。**不做，列为待决策。**

结论：**没有安全的 4 KB。** 按约定停手，不建 PR。`/universe` 慢网记为结构性下限：

- 传输下限 = 135,135 B ÷ 50,000 B/s ≈ **2.70 s**；实测 load 中位数 2.58 s（限速模拟下 TCP 爬坡与并发请求让实际略低于理论串行值）。
- 要进 2.5 s，必须**减少传输字节或提高压缩率**（例如 pre-compress 后发 brotli/zstd 且不牺牲 FCP、或把注释与数据搬到按需加载），而不是继续挪时序。

## 七、构建期去注释（本轮，已实施）

**边界**：`viewer/universe.html` 一个字节不改（本 PR 的 tree 里该文件 blob 与 `main` 相同）；发布件是 `viewer/dist/universe.html`。生成器 `tools/build_viewer.js`；网关 `/universe` 与 `/universe.html` 优先发产物，产物缺失回退源码（不会 404）。

**为什么不用正则**：JS 走手写词法器——字符串、模板串 `${}` 嵌套、正则字面量与除号都按上一个有意义 token 判断，另处理 Annex B 的 `<!--` / 行首 `-->`；HTML 是数据状态机（注释 / 标签含引号属性 / script·style raw text）；CSS 单独跳过字符串与 `url()`。注释被替换成**空格**而不是删除、换行保留，所以产物第 n 行（n≥2）= 源码第 n−1 行；首行写明"由 `viewer/universe.html` 生成、勿手改"并带源 sha256。

**交叉核对**：acorn 8.15.0 `onComment` 得到 1169 条 JS 注释，自研词法给出同样的 1169 个区间，逐条一致 `bad=0`（acorn 只作一次性 oracle，未入库）。

**字节（Python 网关口径 `gzip.compress(raw, 6)`）**：

- raw：351,315 → 282,921 B（−68,394）
- gzip：**135,135 → 79,145 B**（−55,990，−41.4%）
- 本机网关（同一份 `tools/webapp.py`、同一 gzip 口径）`curl --noproxy '*' -H 'Accept-Encoding: gzip'` 实测 `Content-Length: 79145`、`Content-Encoding: gzip`；线上要等这次发布后才生效

**性能**（同机、400 kbps / 50 ms、禁缓存、每轮清 localStorage 冷启、5 轮中位数；源码与产物在同一会话内先后各测一次）：
